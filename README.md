# tenis
VOLT3D — SITE DE TÊNIS 3D

COMO USAR:
1. Abra o arquivo index.html no navegador para testar.
2. Para publicar grátis, use GitHub Pages:
   - Crie uma conta no GitHub.
   - Crie um repositório novo.
   - Envie index.html, a pasta css e a pasta js.
   - Vá em Settings > Pages.
   - Em Build and deployment, selecione Deploy from a branch.
   - Escolha a branch main e a pasta /root.
   - Salve e aguarde o link do site.

OBSERVAÇÃO:
O tênis é criado em CSS/HTML, então não precisa baixar um modelo 3D.
A interação do mouse gira o tênis em tempo real.
